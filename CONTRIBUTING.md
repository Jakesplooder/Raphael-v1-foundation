# Contributing to RaphaelOS

RaphaelOS is a highly specialized project. Contributions must strictly adhere to the Constitutional boundaries of the system.

## Golden Rule
**LLMs Reason. Raphael Decides.**

No pull request will be accepted if it allows a Large Language Model to bypass deterministic governance, alter trust tiers, or overwrite constitutional constraints. Semantic AI is strictly for forecasting, alternatives analysis, and reasoning traces.

## Process
1. Discuss major architectural changes via Issues before writing code.
2. Ensure you have tested `forecast-report` and `build-with-council` locally.
3. Every feature must include deterministic fallback or confidence scaling logic.
