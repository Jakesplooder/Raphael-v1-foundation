# Raphael OS

Raphael OS is a governed AI executive operating system that combines constitutional governance, institutional memory, pattern discovery, executive reasoning, and multi-model AI orchestration to help a human operator plan, build, and manage complex projects safely.

## Vision
To build an executive operating system that separates semantic reasoning from deterministic decision-making, allowing AI to act autonomously within strict constitutional boundaries.

## Core Principles
1. **Constitution First:** Every action is validated against a set of unalterable operational boundaries.
2. **LLMs Reason. Raphael Decides:** Language models are used purely for semantic reasoning (thinking). Governance, authority checks, and final scoring are mathematically deterministic.
3. **Institutional Memory:** The system never forgets past failures, learning patterns over time to predict outcomes more accurately.

## Architecture & Features

### Current v1.0 Foundation Features
- ✓ **Constitution**: Foundational laws governing Raphael's behavior.
- ✓ **Governance**: Rules surrounding authority checking and trust tier escalation.
- ✓ **World Model**: Structured permanent memory storing lessons, events, and nodes.
- ✓ **Institutional Memory**: Ability to retrieve contextual lessons.
- ✓ **Pattern Discovery**: Extracts repeated operational patterns from historical data.
- ✓ **Executive Intelligence**: Formats data to support decisions.
- ✓ **Strategic Planner**: Creates multi-step plans with constitutional limits.
- ✓ **LLM Router**: Multi-provider (Ollama, Claude, Gemini, OpenAI) capability routing with Consensus modes and capability profiles.
- ✓ **Builder**: Scaffold apps based on specifications while safely sandbox-isolating outputs.
