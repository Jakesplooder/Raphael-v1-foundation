# Changelog

All notable changes to RaphaelOS will be documented in this file.

## [v1.0.0] - Foundation Release - 2026-07-06

### Added
- **Constitutional Framework**: Enforces core laws.
- **Governance System**: Defines authority and permissions.
- **World Model**: Permanent graph-based knowledge layer.
- **Institutional Memory**: Discovers and retains lessons from operations.
- **Pattern Discovery**: Identifies repeating trends to guide planning.
- **Executive Intelligence**: Structures data for decision-making.
- **Strategic Planner**: Breaks complex goals into safe steps.
- **LLM Abstraction Layer**: Separates deterministic deciding from semantic reasoning with dynamic capability-based multi-model routing.
- **Forecast Engine**: Predicts outcomes of plans via consensus LLM reasoning and pattern density scoring.
- **Builder**: Deterministically generates safe scaffolded applications from semantic templates.
