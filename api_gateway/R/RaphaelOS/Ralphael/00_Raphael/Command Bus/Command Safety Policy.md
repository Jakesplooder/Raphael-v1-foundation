# Command Safety Policy

## Blocked Centrally

- delete files
- format drive
- install package
- send email
- upload product
- spend money
- publish post
- access credentials
- arbitrary shell command

## Confirmation Required

- write actions
- delegation
- execution
- KPI updates
- finance updates
- builder generation/apply
- world model additions
- portfolio decisions

## Boundary

No arbitrary shell commands, external platform actions, spending, publishing, uploads, email sends, credential access, or destructive file actions are allowed through the Command Bus.
