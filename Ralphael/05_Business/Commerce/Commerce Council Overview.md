# Commerce Council Overview

The Commerce Council plans product-based businesses such as Etsy, print-on-demand, Shopify stores, ebooks, KDP, Gumroad, Payhip, and digital products.

## Boundary

This council plans and prepares commerce operations only. Raphael does not create stores, upload products, spend money, log in to platforms, publish listings, or perform external platform actions.

## Specialist Agents

- Store Manager Agent
- Product Researcher Agent
- Trend Analyst Agent
- Listing Writer Agent
- SEO Specialist Agent
- Customer Support Agent
- Digital Product Agent
- POD Designer Agent
