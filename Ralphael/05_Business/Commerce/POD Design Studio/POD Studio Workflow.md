# POD Studio Workflow

1. Create a concept.
2. Generate model-specific prompts.
3. Create a pending generation request.
4. Confirm local ComfyUI generation.
5. Review generated images with the local vision model.
6. Remove the selected artwork background without overwriting the source.
7. Create editable SVG typography.
8. Compose artwork and typography with configured local Inkscape.
9. Export the editable SVG.
10. Export a transparent 4500 × 5400 print-ready PNG.
11. Create listing, mockup, and IP-safety plans.
12. Confirm and build a local export package.

No external platform action is part of this workflow.
