# POD Design Studio Overview

Raphael's POD Design Studio creates local concepts, prompts, generation requests, design reviews, refactor plans, listing drafts, mockup plans, and export-package metadata.

## Safety Boundary

- Etsy publishing: disabled
- Printify uploads: disabled
- Spending: disabled
- Platform credentials: disabled
- External APIs: disabled
- Source image overwrite: disabled
- Raw image memory indexing: disabled by default
