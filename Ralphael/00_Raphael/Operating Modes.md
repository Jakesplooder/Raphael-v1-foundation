# Operating Modes

Raphael operating modes change priorities, recommended workflows, default agents, and dashboard focus. Modes do not execute actions by themselves.

## Chief of Staff Mode

- Focus: daily command center, priorities, open decisions, blocked tasks, weekly operations review
- Default agents: Chief of Staff Agent, Operations Agent
- Recommended workflows: weekly_operations_review

## Developer Mode

- Focus: active coding projects, technical debt, setup docs, tests, architecture notes
- Default agents: Developer Agent
- Recommended workflows: project_cleanup_review, portfolio_review

## Career Mode

- Focus: portfolio projects, resume bullets, interview talking points, job readiness
- Default agents: Career Agent
- Recommended workflows: portfolio_review

## Student Mode

- Focus: assignments, due dates, submission checklists, academic lessons learned
- Default agents: Academic Agent
- Recommended workflows: assignment_review, weekly_operations_review

## Business Builder Mode

- Focus: business ideas, market research, offers, revenue opportunities, client work
- Default agents: Business Strategy Agent, Marketing Agent, Operations Agent
- Recommended workflows: weekly_operations_review

## Research Mode

- Focus: research notes, source summaries, open questions, knowledge gaps
- Default agents: Research Agent
- Recommended workflows: weekly_operations_review
