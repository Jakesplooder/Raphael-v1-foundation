# Notification Rules

Raphael detects notifications from generated vault/runtime systems.

## Detection Sources

- KPI Review and KPI Registry
- Executive Initiatives
- Opportunity Review and Opportunity Inbox
- Risk Register
- Task Review and agent task files
- Controlled Execution Log and requests
- Builder Requests
- Financial Review
- Business Portfolio Brief
- Council Reviews
- Search Requests
- Vision Requests
- Self-Improvement Reviews
- System Health notes

## Boundary

Detection creates notification records only. No execution happens automatically.
