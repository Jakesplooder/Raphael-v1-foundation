# Blocked Actions

Actions Raphael must not perform without explicit approval, and some it should never perform directly.

| Action Type | Status | Notes |
|---|---|---|
| Delete user data | Blocked | Requires explicit approval and is not implemented in this phase. |
| Move large folders | Blocked | Requires explicit approval and is not implemented in this phase. |
| Install or uninstall software | Blocked | Requires explicit approval. |
| Upload private files | Blocked | Requires explicit approval. |
| Send email or messages | Blocked | Requires explicit approval. |
| Change OS or security settings | Blocked | Requires explicit approval. |
| Access passwords or password managers | Blocked | Never without explicit approval. |
