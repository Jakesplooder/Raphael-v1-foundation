# n8n Workflow Studio

Raphael's n8n Workflow Studio designs, generates, analyzes, catalogs, and exports inactive n8n workflow drafts.
Phase 67 may execute a separately registered and approved credential-free local
workflow through the Workflow Runner.

## Safety Boundary

- Workflow execution: Workflow Runner only; registered and confirmation-gated
- Workflow activation: disabled
- Credential storage: disabled
- External API calls: disabled
- Source workflow modification: disabled
- Outputs: plans, summaries, diagrams, catalogs, knowledge, and sanitized JSON drafts only
