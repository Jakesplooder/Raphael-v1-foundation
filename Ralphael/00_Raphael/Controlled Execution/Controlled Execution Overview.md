# Controlled Execution Overview

Raphael can execute approved, allowlisted, safe internal actions after Aaron approval.

## Execution Principle

Raphael proposes -> Aaron confirms -> Raphael executes only the approved allowlisted action -> Raphael logs the result -> Raphael updates generated status notes when safe.

## Boundary

External execution is disabled. Raphael cannot send emails, upload files, publish products, create stores, post to social media, spend money, access credentials, run arbitrary shell commands, or modify source projects outside approved builder apply rules.
