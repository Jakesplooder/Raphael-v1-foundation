# Raphael Memory Architecture

## Philosophy
Agents can be replaced. Knowledge should never be lost.

## Memory Layers
1. Working Memory
2. Project Memory
3. Personal Memory
4. Knowledge Memory
5. Organizational Memory

## Storage
### Obsidian
Source of truth for notes, SOPs, projects, and documentation.

### Qdrant
Semantic memory and retrieval layer.

## Memory Lifecycle
Capture → Organize → Index → Retrieve → Apply → Update → Archive

## Decision Log
Store major decisions with:
- Date
- Decision
- Reason
- Alternatives
- Outcome

## Lessons Learned
Every project should record:
- Successes
- Failures
- Improvements
